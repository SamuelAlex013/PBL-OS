# Custom OS Project  

This repository contains the source code and configuration files for our custom operating system project.  

## 🚀 Getting Started  

### 1️⃣ **Setting up the Environment**  
Make sure you have the following tools installed:  
- **GRUB** (for bootloader)  
- **NASM** (for assembling kernel code)  
- **QEMU** (for testing)
